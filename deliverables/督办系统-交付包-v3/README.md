## 二、两种运行方式

### 方式 A：源码模式（开发/二次开发）
1. 需要 Python 3.13 + 安装依赖：`pip install -r 03_开发代码/requirements.txt`
2. 进入 `03_开发代码/`，双击 `start.bat` 或执行 `python app.py`
3. 浏览器访问 `http://127.0.0.1:5000`

### 方式 B：离线程序（演示推荐，免装环境）
1. 进入 `05_离线程序/督办系统/`
2. 双击 `start.bat`（或 `督办系统.exe`）
3. 浏览器访问 `http://127.0.0.1:5000`
> 若要局域网其他电脑访问，运行同目录 `开启局域网访问.bat`（需管理员权限）。
