> **文档版本**：v2.0（v1.0 + V2 迭代增补）  
> **编写日期**：2025-08（v1.0）/ 2026-08-28（v2.0 增补）  
> **框架**：Flask 3.x Blueprint

## 2. 认证路由（auth）

**蓝图对象**：`auth_bp = Blueprint('auth', __name__)`  
**权限要求**：无（公开路由）

### 2.1 GET `/` — 根路由重定向

| 项 | 说明 |
|----|------|
| **URL** | `/` |
| **方法** | GET |
| **功能** | 根路由，根据系统状态自动重定向 |
| **权限** | 无 |
| **请求参数** | 无 |

**重定向逻辑**：

| 条件 | 重定向目标 |
|------|-----------|
| 系统无管理员 | `/setup`（初始化向导） |
| 有管理员但未登录 | `/login`（登录页） |
| 有管理员且已登录 | `/dashboard`（仪表盘） |

**响应**：HTTP 302 重定向

### 2.2 GET/POST `/login` — 登录

| 项 | 说明 |
|----|------|
| **URL** | `/login` |
| **方法** | GET / POST |
| **功能** | GET 显示登录表单，POST 提交登录 |
| **权限** | 无（未登录可访问） |
| **请求参数** | 无 |

**POST 表单参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `username` | string | 是 | 用户名 |
| `password` | string | 是 | 明文密码 |
| `remember` | string | 否 | **V2 新增**：勾选"记住我"时写入 30 天用户名 cookie（`remember_username`），不勾选则清除 |

**响应**：

| 场景 | 响应 |
|------|------|
| GET | 渲染 `login.html` 登录页（**V2**：自动回填「记住我」cookie 中的用户名并预勾选） |
| POST 成功 | 302 重定向到 `/dashboard` |
| POST 用户名/密码为空 | **V2**：返回 **400**，渲染登录页并定位到具体字段（`error_field` 字段级红字提示） |
| POST 凭据错误/账号停用 | **V2**：返回 **401**，渲染登录页并显示通用错误（不暴露账号是否存在） |
| 系统无管理员 | 302 重定向到 `/setup` |

**特殊逻辑**：登录失败时统一返回"用户名或密码错误"，不暴露用户是否存在。

### 2.4 GET/POST `/setup` — 初始化向导

| 项 | 说明 |
|----|------|

| **方法** | GET / POST |
| **功能** | 首次启动创建管理员账号 |

| 参数名 | 类型 | 必填 | 校验规则 |

| POST 校验失败 | 渲染 `setup.html`，flash 错误列表 |

## 3. 任务路由（task）

**蓝图对象**：`task_bp = Blueprint('task', __name__)`

### 3.1 GET `/tasks` — 任务列表

| 项 | 说明 |
|----|------|
| **URL** | `/tasks` |
| **方法** | GET |
| **功能** | 任务列表页，支持筛选、搜索、排序、分页 |
| **权限** | `@login_required`（登录用户均可） |

**查询参数**：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `status` | string | 空 | 状态筛选：pending/in_progress/overdue/closed/cancelled |
| `priority` | string | 空 | 优先级筛选：urgent/high/medium/low |
| `assignee` | int | 空 | 负责人 ID 筛选 |
| `keyword` | string | 空 | 标题模糊搜索（LIKE %keyword%） |
| `sort` | string | `due_date_asc` | 排序方式（见下表） |
| `page` | int | 1 | 页码（从 1 开始） |
| `owner` | int | 空 | **V2 新增**：闭环矩阵负责人名字跳转入口，映射到 `assignee` 筛选（等价参数） |

**排序方式**：

| sort 值 | 说明 |
|---------|------|
| `due_date_asc` | 截止日期升序（默认） |
| `due_date_desc` | 截止日期降序 |
| `priority_asc` | 优先级升序（紧急在前） |
| `priority_desc` | 优先级降序 |
| `updated_desc` | 更新时间降序 |
| `updated_asc` | 更新时间升序 |

**响应**：渲染 `tasks/list.html`，传入参数：

| 模板变量 | 类型 | 说明 |
|---------|------|------|
| `tasks` | list[Row] | 当前页任务列表（含 assignee_name / creator_name） |
| `filters` | dict | 当前筛选条件 |
| `page` | int | 当前页码 |
| `total_pages` | int | 总页数 |
| `total` | int | 总记录数 |
| `per_page` | int | 每页条数（20） |
| `active_users` | list[Row] | 启用用户列表（负责人下拉） |
| `statuses` / `priorities` | list | 状态/优先级选项 |
| `current_user` | Row | 当前用户 |
| `can_edit_task` | function | 权限判断函数（模板内调用） |

---

### 3.2 GET/POST `/tasks/new` — 新建任务

| 项 | 说明 |
|----|------|
| **URL** | `/tasks/new` |
| **方法** | GET / POST |
| **功能** | GET 显示新建表单，POST 创建任务 |
| **权限** | `@login_required` |

**POST 表单参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `title` | string | 是 | 任务标题（≤100 字） |
| `description` | string | 否 | 工作要求/描述 |
| `assignee` | int | 是* | 负责人 user_id（owner 角色强制为自己） |
| `priority` | string | 否 | 优先级，默认 medium |
| `due_date` | string | 是 | 截止日期 YYYY-MM-DD |
| `progress_percent` | int | 否 | **V2 新增**：进度百分比 0–100，默认 0（越界时表单校验失败并提示"进度必须在 0-100 之间"） |
| `risk_note` | string | 否 | **V2 新增**：风险点说明（≤500 字） |
| `collaborators` | string | 否 | **V2 新增**：协同方，逗号分隔姓名（≤500 字） |

> *owner 角色创建任务时，`assignee` 被强制设为自己的 user_id，忽略前端传值。
> **V2 兼容**：旧表单/客户端不携带 3 个新字段提交时，字段保留原值（编辑场景）或取默认值（新建场景），不清零。

**响应**：

| 场景 | 响应 |
|------|------|
| GET | 渲染 `tasks/form.html`（is_edit=False） |
| POST 成功 | 创建任务 + 发送指派消息，302 重定向到 `/tasks` |
| POST 校验失败 | 渲染 `tasks/form.html`，flash 错误列表 |

**副作用**：若 assignee != 创建人，自动生成 `assignment` 类型消息通知负责人。

### 3.5 POST `/tasks/<task_id>/status` — 变更状态

| 项 | 说明 |
|----|------|
| **URL** | `/tasks/<int:task_id>/status` |
| **方法** | POST |
| **功能** | 变更任务状态（含进度备注 + 副作用） |
| **权限** | `@login_required` + `can_edit_task` |

**路径参数**：`task_id` (int)

**表单参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `status` | string | 是 | 目标状态 |

| 场景 | 响应 |
|------|------|

### 3.8 POST `/tasks/batch` — 批量操作

| 项 | 说明 |
|----|------|
| **URL** | `/tasks/batch` |
| **方法** | POST |
| **功能** | 批量变更状态或批量指派 |
| **权限** | `@login_required`（reassign 仅管理员） |

**表单参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `task_ids` | list[string] | 是 | 选中的任务 ID 列表 |
| `action` | string | 是 | 操作类型：`change_status` / `reassign` |
| `target_status` | string | 条件必填 | action=change_status 时为目标状态 |
| `new_assignee` | int | 条件必填 | action=reassign 时为新负责人 ID |
| `filter_status` | string | 否 | 原筛选参数（回跳用） |
| `filter_priority` | string | 否 | 原筛选参数 |
| `filter_assignee` | string | 否 | 原筛选参数 |
| `filter_keyword` | string | 否 | 原筛选参数 |
| `filter_sort` | string | 否 | 原筛选参数 |

**响应**：302 重定向到 `/tasks`（携带原筛选参数），flash 结果：

| 场景 | flash 类型 | 消息格式 |
|------|-----------|---------|
| 全部成功 | success | "已批量更新 N 条任务" |
| 部分成功 | warning | "已批量更新 N 条，M 条失败：原因..." |
| 全部失败 | error | "批量操作失败：原因..." |

**权限规则**：
- admin 可批量操作所有任务
- owner 只能批量操作自己负责的任务（不属于自己的跳过并计入失败）

| `closure_rate` | float/None | 闭环率（撤销任务不计分母） |

> V1 的 `week_due` / `my_pending` / `my_urgent` 字段随"我的待办"区块并入焦点列表而移除；V1 的 4 静态统计卡由 6 可点击统计卡替代（点击跳转任务列表对应筛选）。数据来源：`models.get_dashboard_stats_v2` / `get_today_focus` / `get_closure_matrix`。

## 9. 通用约定

### 9.1 错误处理

| HTTP 状态码 | 触发条件 | 响应 |
|-------------|---------|------|
| 403 | 权限不足（`@admin_required` 校验失败） | 渲染 `errors/403.html` 或返回 JSON `{success: false, message: "权限不足"}` |
| 404 | 页面/任务不存在 | 渲染 `errors/404.html` |
| 500 | 服务器内部错误 | 记录日志，渲染 `errors/500.html` |

**403 响应区分**：
- HTML 请求 → 渲染 403 错误页
- JSON 请求（`request.is_json` 或 `request.path.startswith('/api/')`）→ 返回 JSON

### 9.2 权限装饰器

| 装饰器 | 校验逻辑 | 失败行为 |
|--------|---------|---------|
| `@login_required` | session 中无 user_id 或用户不存在 | 302 重定向到 `/login` |
| `@admin_required` | 未登录 → 重定向登录；已登录非 admin | 403 错误页或 JSON |

### 9.3 数据级权限函数

| 函数 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `can_edit_task(task, user)` | 任务对象, 用户对象 | bool | admin 可编辑所有；owner 仅自己负责的 |
| `can_delete_task(task, user)` | 任务对象, 用户对象 | bool | 仅 admin 且任务状态为 cancelled |
| `get_current_user()` | — | Row/None | 从 session 获取当前登录用户 |

### 9.4 Flash 消息分类

| 分类 | 用途 | 前端样式 |
|------|------|---------|
| `success` | 操作成功 | 绿色 |
| `error` | 操作失败/校验错误 | 红色 |
| `warning` | 部分成功 | 橙色 |
| `info` | 提示信息 | 蓝色 |

### 9.5 JSON 响应格式

所有 JSON 接口统一格式：

```json
// 成功
{
  "success": true,
  "data": [...],       // 或 "count": N, "message": "..."
}

// 失败
{
  "success": false,
  "message": "错误原因"
}
```
