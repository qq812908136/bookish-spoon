## 二、Python 源文件说明

### 2.1 根目录模块

| 文件 | 职责 |
|------|------|
| **app.py** | Flask 应用工厂入口。负责创建 Flask 应用、加载配置、初始化数据库（建表 + 默认配置）、注册全部蓝图、注册错误处理器（403/404/500）、注册 Jinja2 自定义过滤器（日期格式化/状态标签/颜色映射）、注入全局模板上下文（current_user / unread_count / 预警配置）、启动后台守护线程（逾期扫描 + 预警扫描）、自动打开浏览器。支持 `--seed-demo` 和 `--clear-demo` 命令行参数。 |
| **config.py** | 全局配置集中管理。包含：PyInstaller 冻结检测（区分开发模式与打包模式）、路径配置（BASE_DIR / BUNDLE_DIR / TEMPLATE_DIR / STATIC_DIR / DATABASE_PATH）、安全配置（SECRET_KEY / session 有效期）、分页配置（每页 20 条）、后台扫描配置（逾期扫描 5 分钟 / 预警扫描每日 09:00）、预警默认值（到期 3 天 / 待激活 7 天）、服务器配置（HOST / PORT / DEBUG）、消息轮询间隔（30 秒）。 |
| **db.py** | SQLite 连接管理（线程安全）。基于 threading.local 实现每线程独立连接 + 全局写锁保证事务原子性。提供 get_db()、transaction() 上下文管理器、query() / query_one() / execute() 快捷方法、close_db() 资源清理。连接配置：row_factory=Row（字典式访问）、外键约束启用。 |
| **models.py** | 数据访问层（DAL）。包含 init_db() 建表 + 建索引 + 写默认配置，以及全部 CRUD：用户管理（创建/查询/启停/改密/改名）、任务管理（含分页/筛选/排序/模糊搜索/动态更新/逾期查询/预警查询）、进度记录管理、消息管理（创建/列表/标记已读/未读计数/预警去重）、系统配置管理（get/set）、仪表盘统计（总量/各状态数/本周到期/我的待办/我的紧急）。 |
| **auth.py** | 认证与权限模块（RBAC）。包含：密码哈希工具（werkzeug PBKDF2）、登录/登出流程（do_login / do_logout）、权限装饰器（@login_required / @admin_required，区分 JSON 与 HTML 响应）、当前用户获取（get_current_user）、数据级权限判断（can_edit_task / can_delete_task / filter_tasks_by_permission）。权限模型：admin 管理所有，owner 可查看全部任务（只读他人）仅编辑自己负责的任务。 |
| **state_machine.py** | 任务状态机。定义 5 种状态（pending/in_progress/overdue/closed/cancelled）+ 4 种优先级（urgent/high/medium/low）+ 中文/颜色映射。核心：转换矩阵（TRANSITIONS 定义合法转换，ADMIN_ONLY_TRANSITIONS 标记管理员专属操作）、validate_transition() 校验函数、get_allowed_transitions() 获取下拉选项、change_task_status() 完整状态变更流程（事务性：更新状态 + 写进度日志 + 发通知消息 + 副作用处理如闭环时间/逾期标记）。 |
| **warning_engine.py** | 三层预警引擎。第一层：即将到期预警（截止前 N 天，状态为待启动/进行中，仅通知负责人）；第二层：已逾期预警（每日提醒，通知负责人 + 管理员）；第三层：长期待激活预警（创建超 N 天仍未启动，每 N 天提醒一次，通知负责人 + 管理员）。特性：多层预警合并为一条消息（避免轰炸）、当天去重（同任务同接收人同类型只发一条）、trigger_overdue_warning() 实时逾期触发。 |
| **scheduler.py** | 后台守护线程调度。启动两个 daemon 线程：逾期扫描线程（每 5 分钟，查找 pending/in_progress 且超截止日期的任务，自动标记 overdue + 写系统进度日志 + 触发逾期预警消息）、预警扫描线程（每分钟检查是否到达配置的扫描时间，到点执行三层预警扫描）。线程安全依赖 db.py 的 threading.local + 全局写锁。 |
| **seed_demo_data.py** | 演示数据灌入脚本。独立运行 `python seed_demo_data.py`（或 `督办系统.exe --seed-demo`）即可灌入演示数据：9 个用户（1 管理员 + 8 负责人）、45 个任务（覆盖全部 5 种状态，含即将到期/已逾期/长期待激活预警场景，并补写 V2 字段、过程证据、阻塞记录）、67 条消息通知。如检测到已有数据，自动清空后重建。 |
| **test_suite.py** | 综合测试套件（73 项）。覆盖：数据库初始化测试、状态机转换测试（合法/非法/权限/副作用）、应用启动与路由可访问性测试、端到端功能测试、权限测试（未登录拦截/角色隔离/数据级权限）、分页测试（C1 每页 20 条）、预警引擎测试（三层预警/去重）。运行方式：`python test_suite.py`。 |

### 2.2 routes/ 路由模块

| 文件 | 职责 |
|------|------|
| **routes/\_\_init\_\_.py** | 蓝图注册汇总。提供 register_blueprints(app) 函数，统一注册 7 个功能模块的 Flask Blueprint（auth/task/progress/message/user/settings/dashboard）。延迟导入避免循环依赖。 |
| **routes/auth_routes.py** | 认证路由。GET / 根路由重定向（已登录→仪表盘，未登录→登录页，无管理员→初始化向导）；GET/POST /login 登录；GET /logout 登出；GET/POST /setup 首次启动初始化向导（创建管理员账号，含用户名/密码/确认密码表单校验）。 |
| **routes/dashboard_routes.py** | 仪表盘路由（P1）。GET /dashboard 仪表盘概览页，调用 models.get_dashboard_stats() 获取统计数据（总量/各状态数/本周到期/我的待办/我的紧急），渲染统计卡片 + 状态分布。 |
| **routes/task_routes.py** | 任务路由（核心模块）。GET /tasks 任务列表（筛选+搜索+排序+分页）；GET/POST /tasks/new 新建任务（owner 仅指派给自己）；GET /tasks/<id> 任务详情（侧滑面板，AJAX 加载）；POST /tasks/<id>/edit 编辑任务；POST /tasks/<id>/status 状态变更（含进度备注+副作用）；POST /tasks/<id>/delete 物理删除（仅管理员，仅已撤销任务）；GET /tasks/export CSV 导出（P1-004，utf-8-sig BOM 兼容 Excel）；POST /tasks/batch 批量操作（P1-003，批量改状态/批量指派）。 |
| **routes/progress_routes.py** | 进度记录路由。POST /tasks/<id>/progress 提交进度备注（不改状态，仅记录日志+更新 updated_at）；GET /tasks/<id>/logs 查看进度记录（JSON 格式，供侧滑面板异步加载时间线）。 |
| **routes/message_routes.py** | 消息通知路由。GET /messages 消息列表（筛选类型/已读状态）；POST /messages/<id>/read 标记单条已读（JSON）；POST /messages/read-all 全部已读（JSON）；GET /messages/unread-count 未读数（JSON，导航栏红点 30 秒轮询，C2 确认）；GET/POST /messages/send 管理员发消息（C3 确认，选择接收人+输入内容+可选关联任务）。 |
| **routes/user_routes.py** | 用户管理路由（P1，仅管理员）。GET /users 用户管理页；POST /users/new 新增用户（用户名/显示名/密码/角色校验）；POST /users/<id>/toggle 启用/停用用户（不允许停用自己、不允许停用最后一个管理员）；POST /users/<id>/reset-password 重置密码。 |
| **routes/settings_routes.py** | 设置路由。GET/POST /settings/profile 个人设置（修改显示名、修改密码，需验证原密码）；GET/POST /settings/system 系统设置（管理员，预警天数配置：到期预警 1-30 天、待激活预警 1-90 天）。 |
