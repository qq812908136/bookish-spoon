# 督办系统 — 项目目录结构说明

> 更新时间：2026-08-31（src 分层重构后）
> 技术栈：Python 3.13 + Flask 3.0.3 + SQLite
> 打包工具：PyInstaller 6.10.0（onedir 模式）

## 〇、仓库顶层结构（src 分层）

```
督办系统/                          ← 仓库根 = 项目根
├── src/                           ← 应用源码（Flask 全部代码与资源）
├── tests/                         ← 测试套件与测试数据库
├── scripts/                       ← 构建 / 汇编脚本
├── docs/                          ← 全部文档
├── data/                          ← 运行时数据库（不入库）
├── logs/                          ← 运行日志（supervision.log，自动轮转，不入库）
├── deliverables/                  ← 交付包（v3 已发行，v4 为当前版本）
├── _archive/                      ← 归档区（历史产物，不入库）
├── .github/workflows/             ← CI 配置
│
├── start.bat                      ← 双击启动（本机模式，默认只监听 127.0.0.1）
├── 局域网启动.bat                  ← 局域网模式启动（设 HOST=0.0.0.0）
├── build.bat                      ← 打包（调用 督办系统.spec）
├── 清除数据.bat                    ← 清空所有数据
├── 灌入演示数据.bat                ← 灌入 9 用户 / 45 任务 / 67 消息
├── 开启局域网访问.bat              ← 防火墙放行 5000 端口（需管理员，配合局域网启动.bat）
├── 督办系统.spec                  ← PyInstaller 打包配置（入口 src/app.py）
├── requirements.txt               ← Python 依赖清单
├── .env.example                   ← 环境变量配置模板（复制为 .env 生效，.env 不入库）
├── CHANGELOG.md                   ← 版本变更记录
└── README.md                      ← 项目说明
```

### 目录职责

| 目录 | 存放内容 | 说明 |
|------|----------|------|
| `src/` | 应用代码 | 10 个 Python 模块（含 `csrf.py`）+ `routes/` + `templates/` + `static/` |
| `tests/` | 测试 | `test_suite.py`（161 项）、`generate_test_report.py`、`test_data/`（测试库，不入库） |
| `scripts/` | 构建与自查脚本 | `build_delivery_package.py`（交付包汇编）、`check_bat_encoding.py`（bat 编码守卫） |
| `docs/` | 文档 | 全项目文档唯一真相源，入口见 **`docs/README.md`**（含命名对照表与文档地图）；含设计文档、缺陷清单、上线前待办、迭代记录（`docs/迭代记录/`）、测试报告 |
| `data/` | 运行时数据 | `supervision.db` + `backup/`（历史备份）；数据库不入库 |
| `logs/` | 运行日志 | `supervision.log`，按大小轮转（单文件 2 MB、保留 5 份）；运行期生成，不入库 |
| `deliverables/` | 交付包 | v3（已发行，只读）+ v4（当前）及其 zip |
| `_archive/` | 归档 | `build/` `dist/` 旧发行版 zip / env_info.txt / v1-v2 交付包目录 |
| `.github/workflows/` | CI | `ci.yml`：push/PR 跑测试（Windows + Python 3.11/3.12），打 tag 时额外打包离线程序 |

### 路径推导约定（重要）

`src/config.py` 用自身位置推导两类目录，改动目录结构时必须同步：

| 变量 | 取值 | 用途 |
|------|------|------|
| `BASE_DIR` | `src/` 的上一级 = 项目根 | 数据库目录 `data/` 挂在这里 |
| `BUNDLE_DIR` | `src/`（config.py 所在目录） | `templates/` 与 `static/` 挂在这里 |

打包后（`sys.frozen=True`）两者分别退化为 `dirname(sys.executable)` 与 `sys._MEIPASS`，逻辑不变。

## 二、Python 源文件说明

### 2.1 src/ 根模块

| 文件 | 职责 |
|------|------|
| **src/app.py** | Flask 应用工厂入口。创建应用、加载配置、初始化数据库（建表 + 默认配置）、注册全部蓝图、注册错误处理器（403/404/500）、注册 Jinja2 自定义过滤器、注入全局模板上下文、启动后台守护线程（逾期扫描 + 预警扫描）、自动打开浏览器。支持 `--seed-demo` 与 `--clear-demo` 命令行参数。 |
| **src/config.py** | 全局配置集中管理。PyInstaller 冻结检测、路径配置（BASE_DIR / BUNDLE_DIR / TEMPLATE_DIR / STATIC_DIR / DATABASE_PATH）、安全配置（SECRET_KEY / session 有效期）、分页配置、后台扫描配置（逾期 5 分钟 / 预警每日 09:00）、预警默认值（到期 3 天 / 待激活 7 天）、服务器配置（HOST / PORT / DEBUG）、消息轮询间隔（30 秒）。 |
| **src/db.py** | SQLite 连接管理（线程安全）。基于 `threading.local` 实现每线程独立连接 + 全局写锁。提供 `get_db()`、`transaction()`、`query()` / `query_one()` / `execute()`、`close_db()`。 |
| **src/models.py** | 数据访问层（DAL）。`init_db()` 建表 + 索引 + 默认配置，以及全部 CRUD：用户、任务（分页/筛选/排序/搜索/逾期/预警）、进度记录、消息、系统配置、仪表盘统计。 |
| **src/auth.py** | 认证与权限（RBAC）。密码哈希（werkzeug PBKDF2）、登录/登出、权限装饰器（`@login_required` / `@admin_required`）、当前用户获取、数据级权限判断（`can_edit_task` / `can_delete_task` / `filter_tasks_by_permission`）。 |
| **src/state_machine.py** | 任务状态机。5 状态（pending/in_progress/overdue/closed/cancelled）+ 4 优先级 + 中文/颜色映射；转换矩阵 `TRANSITIONS` 与 `ADMIN_ONLY_TRANSITIONS`；`validate_transition()` / `get_allowed_transitions()` / `change_task_status()`（事务性：改状态 + 写进度日志 + 发通知 + 副作用）。 |
| **src/warning_engine.py** | 三层预警引擎。即将到期（截止前 N 天，通知负责人）、已逾期（每日提醒，通知负责人 + 管理员）、长期待激活（创建超 N 天未启动，每 N 天一次）。多层合并为一条消息、当天去重、`trigger_overdue_warning()` 实时触发。 |
| **src/scheduler.py** | 后台守护线程调度。逾期扫描线程（每 5 分钟，自动标记 overdue + 写系统日志 + 触发预警）、预警扫描线程（每分钟检查是否到点执行三层预警）。 |
| **src/seed_demo_data.py** | 演示数据灌入。9 个用户（1 管理员 + 8 负责人）、45 个任务（覆盖 5 种状态与三类预警场景）、67 条消息。已有数据时自动清空后重建。 |

### 2.2 src/routes/ 路由模块

| 文件 | 职责 |
|------|------|
| **routes/\_\_init\_\_.py** | 蓝图注册汇总。`register_blueprints(app)` 统一注册 7 个 Blueprint，延迟导入避免循环依赖。 |
| **routes/auth_routes.py** | 认证路由。根路由重定向、登录、登出、首次启动初始化向导。 |
| **routes/dashboard_routes.py** | 仪表盘路由。`GET /dashboard` 统计卡片 + 状态分布。 |
| **routes/task_routes.py** | 任务路由（核心）。列表（筛选/搜索/排序/分页）、新建、详情（侧滑面板 AJAX）、编辑、状态变更、删除（仅管理员 + 已撤销）、Excel 导出、批量操作。 |
| **routes/progress_routes.py** | 进度记录路由。提交进度备注、查看进度时间线（JSON）。 |
| **routes/message_routes.py** | 消息通知路由。列表、标记已读、全部已读、未读计数（红点轮询）、管理员发消息。 |
| **routes/user_routes.py** | 用户管理路由（仅管理员）。列表、新增、启用/停用、重置密码。 |
| **routes/settings_routes.py** | 设置路由。个人设置（显示名/密码）、系统设置（预警天数配置）。 |

## 三、测试与脚本

| 路径 | 职责 |
|------|------|
| **tests/test_suite.py** | 综合测试套件（121 项）。覆盖数据库初始化、状态机、路由可访问性、端到端流程、权限、分页、预警引擎、V2 仪表盘与行内编辑、抽屉路由、推送提醒、登录与暗色模式。运行：`python tests/test_suite.py` 或 `python -m unittest tests.test_suite`。 |
| **tests/generate_test_report.py** | 报告生成器。真实运行 test_suite 并输出 Markdown 报告、HTML 报告、逐用例清单、`test_summary.json`。默认输出 `docs/测试报告/`，可用命令行参数指定输出目录。 |
| **tests/test_data/** | 测试专用数据库目录（每次运行自动重建，不入库）。 |
| **scripts/build_delivery_package.py** | 交付包汇编脚本。基于 `__file__` 推导项目根，从源码实时复制生成 `deliverables/督办系统-交付包-vN/` 并打包 zip。具备：版本白名单闸门（v1/v2/v3 拒绝重建）、保留离线演示库、同步最新 exe、**同步仓库根 bat 到离线目录**、去「-最新」易腐命名、排除 `secret.key`。 |
| **scripts/check_bat_encoding.py** | bat 编码守卫。检查全仓库 `.bat`/`.cmd` 是否均为 **GBK + CRLF**，不合格则列出文件与原因并以退出码 1 结束。改动任何启动脚本后都应跑一次：`python scripts/check_bat_encoding.py`。 |

## 四、部署配置文件说明

| 文件 | 用途 |
|------|------|
| **requirements.txt** | Python 依赖清单。运行时 Flask==3.0.3 + openpyxl；打包时 PyInstaller。 |
> **5 个启动 bat 都是「运行方式自适应」的**：目录里有 `督办系统.exe` 就直接跑 exe（离线模式），
> 没有就用 Python 跑 `src\app.py`（源码模式）。因此**仓库根与离线程序共用同一份脚本**，
> 不必维护两套；仓库根是唯一真相源，构建时会自动同步进 `05_离线程序/`。

| 文件 | 用途 |
|------|------|
| **start.bat** | 启动脚本（**本机模式**）。切换中文编码（chcp 936）、优先使用托管 Python。默认只监听 `127.0.0.1`，只有这台电脑能访问。 |
| **局域网启动.bat** | 启动脚本（**局域网模式**）。唯一区别是启动时设 `HOST=0.0.0.0`，让局域网内其他设备也能访问，并打印局域网地址。 |
| **开启局域网访问.bat** | 防火墙放行 TCP 5000（需管理员权限，每台机器一次）。**只管防火墙**，服务本身仍要配合 `局域网启动.bat` 才会对外监听。 |
| **清除数据.bat** | 清空所有数据（执行 `src\app.py --clear-demo`），恢复初始状态。 |
| **灌入演示数据.bat** | 灌入 9 用户 / 45 任务 / 67 消息（执行 `src\app.py --seed-demo`）。 |
| **build.bat** | 打包脚本。检查 Python → 安装依赖 → `python -m PyInstaller 督办系统.spec --noconfirm` → 输出 `dist\督办系统\`。**打包参数集中在 spec 中，不再重复写命令行参数**。 |
| **督办系统.spec** | PyInstaller 配置（onedir）。入口 `src/app.py`，`pathex=['src']`，打包 `src/templates` 与 `src/static`，隐藏导入 flask + openpyxl。 |

> ⚠️ **bat 编码铁律**：所有 `.bat` 必须 GBK（ANSI）+ CRLF。cmd.exe 默认按 GBK 解码，UTF-8（含 BOM）或 LF 换行会导致中文乱码并把乱码当命令执行。
> 用 Edit/Write 工具直接改 bat 极易踩这个坑（它们默认写 UTF-8）。改完务必跑一次 `python scripts/check_bat_encoding.py` 自查。
