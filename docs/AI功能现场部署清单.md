# AI 功能现场部署清单（演示机 / 客户机通用）

> 适用版本：V5 交付包（`deliverables/督办系统-交付包-v5/`）
> 目标：在**离线 / 内网**环境把「AI 辅助」跑起来，全程数据不出本机。
> 设计前提：AI 默认关闭，必须在 `.env` 中显式 `AI_ENABLED=true` 并配好本地模型后才生效。

---

## 一、原理一句话

V5 的 AI 走**本地模型（Ollama）**，默认地址 `http://127.0.0.1:11434`。
只要本机装好 Ollama 并加载模型，**运行时不需要联网**，督办数据也不会传出机器。

> ⚠️ 若把 `AI_PROVIDER` 改成 `cloud`（云端接口），则需要联网且数据会出网，**内部督办数据不推荐**。本清单只讲本地（local）模式。

---

## 二、现场 6 步（按顺序做）

### 1. 安装 Ollama（只需一次）
- 到 https://ollama.com 下载 Windows 版安装包，双击安装。
- 完全断网环境：先在有网的机器装好 → 拉好模型 → 把 `%USERPROFILE%\.ollama` 整个目录拷到目标机同名路径。

### 2. 拉取模型
```bat
ollama pull qwen2.5:7b
```
- 模型名要和 `.env` 里的 `AI_MODEL_NAME` 一致（默认 `qwen2.5:7b`）。
- 机器性能弱、嫌慢，可换成更小的 `qwen2.5:3b`，并把 `.env` 的 `AI_MODEL_NAME` 同步改成 `qwen2.5:3b`。
- 确认：`ollama list` 能看到 `qwen2.5:7b`。

### 3. 让 Ollama 常驻（关键，否则会报连接失败）
- 桌面版 Ollama 安装后会随系统托盘常驻；**确认右下角托盘有 Ollama 图标、且服务已启动**。
- 纯命令行环境：`ollama serve` 在前台跑着即可（别关窗口）。
- 想开机自启：把 `ollama serve` 放进「任务计划程序」或开机启动项。
- 🔴 之前在开发机遇到的「AI 生成失败 / WinError 10061」就是 Ollama 没起，务必先确认这一步。

### 4. 写 `.env`（放在 `督办系统.exe` 同级目录）
内容如下（直接复制，按需改模型名）：
```ini
AI_ENABLED=true
AI_PROVIDER=local
AI_API_BASE_URL=http://127.0.0.1:11434
AI_MODEL_NAME=qwen2.5:7b
AI_MASK_DATA=true
# 可选：每日自动生成简报；不需要定时就留 off
AI_BRIEF_SCHEDULE=off
```
- 优先级：系统环境变量 > `.env` 文件 > 代码默认值。不写就用默认值（AI 关闭）。
- `.env` 已进 `.gitignore`，**不要提交进仓库**，每台机器各自配。

### 5. 重启「督办系统.exe」
- **改 `.env` 不生效，必须重启程序**才会重新读取。
- 关掉正在运行的 exe / 源码进程，再双击 `督办系统.exe`（或 `start.bat`）。

### 6. 用管理员账号登录，验证入口
- 顶部导航（管理员可见）出现「**AI 辅助**」入口 → 点进 `/ai` 控制台。
- 控制台显示「AI 功能当前已启用」即为成功。
- 任务详情页（管理员）会出现「AI 催办话术」卡片，可一键生成草稿。

---

## 三、页面入口在哪

| 入口 | 位置 | 权限 |
|---|---|---|
| AI 辅助导航 | 顶部导航栏（移动端在汉堡菜单内），位于「邮件」之后 | 管理员 |
| AI 控制台 | `/ai`：开关概览、生成记录、催办/结构化建任务/简报周报 | 管理员 |
| AI 催办话术 | 任务详情页内卡片，「生成催办话术」 | 管理员 |
| AI 结构化建任务 | AI 控制台「AI 结构化建任务」 | 管理员 |
| 简报 / 周报 | AI 控制台「生成简报 / 周报」 | 管理员 |

> 非管理员（负责人）看不到 AI 入口；AI 未启用时控制台仍可达，但点生成会提示「请在 .env 设置 AI_ENABLED=true」。

## 四、注意事项（现场别踩）

1. **只跑一个实例**：本机同时起多个「督办系统」进程（每个实例 `data/secret.key` 不同，Cookie 按端口混用）会导致会话/CSRF 400。演示前关掉多余的，重启后刷新或重登。
2. **CPU 跑 7B 模型偏慢**：首次生成含模型冷加载，可能 10–60 秒；UI 有加载态，现场提前心里有数。性能不足换 `qwen2.5:3b`。
3. **人工确认才发**：简报 / 催办都是 AI 出草稿，必须管理员点「确认」才作为站内信发出 —— 不会自动发送。
4. **脱敏默认为开**（`AI_MASK_DATA=true`）：送模型前会遮蔽手机号 / 邮箱 / 证件号。
5. **演示库账号**：管理员 `admin` / 口令 `Supv#Admin2026`；负责人 `owner01`…`owner08` / `Supv#Owner2026`。改密码若在「用户管理」页报 400，可让该用户在「设置」页自助改（不受影响）。

## 五、快速排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 点生成报「AI 功能未启用」 | `.env` 没配或没重启 | 检查第 4、5 步，重启 exe |
| 生成失败 / 连接被拒（10061） | Ollama 没起 | 第 3 步，确认托盘图标 / `ollama serve` |
| 生成极慢或卡住 | 模型在冷加载 / 机器弱 | 等首调；换 3b 模型 |
| 导航看不到「AI 辅助」 | 用的不是管理员账号 | 用 admin 登录 |
| 改 `.env` 后无变化 | 没重启程序 | 关掉 exe 重开 |
