## 修复 bat 脚本 cd 命令引号陷阱

- 问题：`cd /d "%~dp0"` 中 `%~dp0` 展开后路径末尾带 `\`，与结尾引号形成 `\"` 转义，导致 CMD 引号不匹配、整批脚本被切碎解析
- 表现：`灌入演示数据.bat`、`start.bat`、`清除数据.bat` 运行时出现乱码 + "不是内部或外部命令"
- 修复：所有 bat 文件改为 `cd /d %~dp0`（去掉引号），统一换行为 CRLF
- 受影响文件（源码版 + 打包版共 7 个）：start.bat / 灌入演示数据.bat / 清除数据.bat / build.bat / 开启局域网访问.bat
- 重新打包 zip：督办系统-发行版.zip（12.4MB，根目录）

## 修复 bat 脚本引号嵌套错误

- 问题：`for /f` 循环中调用 Python 命令，Python 代码里的单引号 `('8.8.8.8',80)` 与 `for` 的 `in ('...')` 引号冲突，导致 CMD 解析错乱（乱码 + 命令未识别）
- 修复方案：改用 `wmic nicconfig where "IPEnabled=TRUE" get IPAddress /value` 获取局域网 IP，彻底避开引号嵌套
- 受影响文件：
  - `开启局域网访问.bat`（源码版 + 打包版）
  - `start.bat`（源码版 + 打包版）
- 验证：所有 bat 文件编码为 GBK（936），无单引号
- 重新打包 zip：督办系统-发行版.zip（12.4MB，根目录）

## 修复 wmic 获取 IP 时混入 IPv6 地址

- 问题：`wmic nicconfig where "IPEnabled=TRUE" get IPAddress /value` 返回的 IPAddress 字段同时包含 IPv4 和 IPv6（如 `{192.168.31.199, fe80::71a8:d060:d1ab:9779}`），bat 的 `for` 循环把整串当做一个值，导致显示 `http://(192.168.31.199,fe80::...):5000`
- 修复方案：改用 `ipconfig | findstr /i "IPv4"` 过滤出纯 IPv4 行，再用 `for /f` 提取地址
- 好处：同时避开 `wmic` 的数组格式问题和 `for /f ('命令')` 的单引号陷阱
- 受影响文件：`start.bat`（源码版 + 打包版）、`开启局域网访问.bat`（源码版 + 打包版）
- 重新打包 zip：督办系统-发行版.zip（12.4MB，根目录）
